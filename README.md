# Telegram-бот для приёма заказов

Две роли: **клиент** и **поставщик**. Поставщик определяется по Telegram ID, все остальные клиенты.

## Что умеет

Клиент:
- 🛒 Заказ: товар кнопкой, количество кнопками «−/+» или числом, корзина, дата (не раньше чем через 2 дня), время, ФИО, телефон; перед подтверждением кнопки «Редактировать» и «Готово»
- после «Готово» бот присылает сумму и реквизиты предоплаты 50%
- 💰 Прайс (картинка), 📦 Мои заказы (со статусами и отменой, пока заказ новый)
- ФИО и телефон запоминаются для следующих заказов

Поставщик (всё то же, плюс):
- 🆕 новый заказ сразу приходит в чат с кнопками «Подтвердить» / «Отклонить», дальше «Выполнен» / «Отменить»; клиент получает уведомление о смене статуса
- 📋 Заказы: таблица-картинка и по сообщению на каждый активный заказ
- 🗂 Все заказы: таблица со всей историей

## Запуск на своём компьютере

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # заполните BOT_TOKEN, SUPPLIER_IDS, PAY_PHONE, PAY_BANK
python bot.py
```

1. Создайте бота у @BotFather, токен вставьте в `BOT_TOKEN`.
2. Свой Telegram ID узнайте у @userinfobot и вставьте в `SUPPLIER_IDS` (несколько через запятую).
3. Каждый поставщик должен один раз нажать `/start` у бота, иначе бот не сможет писать ему первым.

## Деплой на Render

1. Загрузите проект в репозиторий GitHub (`.env` не коммитьте, он в `.gitignore`).
2. На Render: New → Web Service → выберите репозиторий.
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
3. В Environment добавьте переменные: `BOT_TOKEN`, `SUPPLIER_IDS`, `PAY_PHONE`, `PAY_BANK`, `PYTHON_VERSION=3.12.7`.
4. **База данных.** Файловая система Render стирается при каждом перезапуске и деплое. Чтобы заказы не пропадали:
   - подключите Disk (платный план): Mount Path `/var/data`, и добавьте переменную `DB_PATH=/var/data/orders.db`.
   - Без диска бот работает, но история заказов обнуляется при перезапуске.
5. На бесплатном плане Web Service засыпает без входящих запросов, и бот перестаёт отвечать. Нужен платный план либо внешний пинг адреса сервиса раз в 5–10 минут.

## Правки без программирования

- Товары и цены: `catalog.py`
- Реквизиты и процент предоплаты: переменные окружения
- Картинка прайса: `assets/price.jpg`
- Минимум дней до даты заказа: `MIN_DAYS_AHEAD`

## Структура

```
bot.py               запуск
config.py            настройки
catalog.py           товары и цены
db.py                SQLite (пользователи, заказы)
table_image.py       таблица заказов картинкой
utils.py, ui.py      форматирование, проверка ввода, клавиатуры
notify.py            рассылка поставщикам и клиентам
handlers/client.py   сценарий клиента
handlers/supplier.py сценарий поставщика
```
